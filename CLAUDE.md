# CLAUDE.md – Hauskauf Bonn

This repo is the owner's go-to tool for buying a home in Bonn. It is a **public** GitHub repo published with
GitHub Pages, so privacy rules below are strict.

**First thing in a new session:** if `private/HANDOFF.md` exists, read it. It holds the personal context
(budget, preferences, decisions, next steps) from the conversation that created this repo. Never copy anything
from `private/` into tracked files, commit messages, issues or PR descriptions.

## Privacy rules (non-negotiable)

- `private/` is git-ignored and must stay that way. Check `git status --ignored` before committing.
- Tracked files contain **no personal data**: no names, emails, income, savings, equity, current rent, family
  details, or anything that identifies the owner or private sellers/tenants.
- Listing locations are **district-level only**. Never add street addresses or exact coordinates of private homes,
  and never try to work out an address the listing doesn't publish.
- Published money figures are either listing facts or **relative** model results (difference vs the reference
  home) and a neutral standard financing (70% of all-in borrowed at 4.15%, 3% repayment).
- Commit as `thomascamminady <24543638+thomascamminady@users.noreply.github.com>` (GitHub noreply address).

## Common tasks

- **Add a listing:** append to `data/listings.json` (copy an existing entry; set `id`, `category`, `type`,
  `district` + `lat`/`lon` from `data/market.json` district centre, facts, `scores`, `short`). For shortlist
  entries, add model parameters in `private/compute.py`, run
  `uv run --with numpy --with matplotlib --with fire python private/compute.py`, then `uv run scripts/build.py`.
  The page only shows shortlist entries that have model results.
- **Private view:** `uv run scripts/build.py --private_model=private/model_private.json --out=private/overview_private.html`.
- **Refresh market data:** ImmoScout24 search pages per district (`/Suche/de/nordrhein-westfalen/bonn/<bezirk>/<district>/wohnung-kaufen`
  and `/haus-kaufen`) show “Ø Kaufpreis/m²” and trend in the market-insights box; update `data/market.json`.
- **Check the page:** render it (e.g. headless Chrome screenshot) and look at it before committing.

## Scoring rubric (0–5, judgement from listings)

- **location** – Ippendorf / Kottenforst edge / Röttgen 5; Lengsdorf, Friesdorf, Schweinheim 4; central Godesberg 3;
  Mehlem / Wachtberg 2–3; Heiderhof 1–2 (owner isn't keen).
- **guests** (long family visits) – separate flat 5; guest room with own bath 4; two baths 3; one bath 2.
- **space** – roughly (m² − 90) / 20, capped at 5.
- **condition** – new / renovated + efficient 5 … needs full renovation, oil or electric heating 1–2.
- **risk** – clean sale 4–5; tenant, damp, big renovation, unknown service charge lower.

## Code style

Python with strong type hints; uv scripts with inline dependencies; Google `fire` for CLIs (not argparse);
polars for data work, matplotlib for static plots; keep `ruff` (line length 120) and `ty` clean.
